# Contributing

Thank you for your interest in contributing.

## How to Contribute

1. Fork this repository.
2. Create a new branch.
3. Make your changes.
4. Test your code.
5. Submit a Pull Request.

## Coding Guidelines

- Use meaningful module names.
- Add comments where appropriate.
- Maintain Verilog coding standards.
- Ensure successful simulation before submitting.

## Reporting Issues

Please open a GitHub Issue with:

- Description
- Steps to reproduce
- Expected behaviour
- Screenshots (if applicable)
